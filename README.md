# Resume Website – HTML & CSS

A personal resume webpage created by **Enugula Rakesh** using HTML and CSS. This project is part of my practice in building and styling web pages.

## About the Project

The webpage presents my resume in a browser, including my name, contact information, professional summary, and resume details.

## Technologies Used

- **HTML5** – Structures the resume content.
- **CSS3** – Styles the webpage.

## Project Files

```text
RESUME-html-css/
├── resume.html
├── resume.css
└── README.md
```

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/rakesh-0010/RESUME-html-css.git
   ```

2. Open the project folder.
3. Double-click `resume.html` to view the webpage in your browser.

You can also open the folder in VS Code and use the Live Server extension.
